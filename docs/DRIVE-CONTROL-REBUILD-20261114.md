# 주행 제어 수정 · 2026-11-14

실행 버전: `20261114-control-rebuild`. 기존 내비게이션, B 조건의 설명·선택·실행·결과 흐름과 음성 캐시는 유지한다.

## 무엇이 꼬였는가

화면만의 정렬 문제가 아니었다. 차량의 도로 위치 계산과 동기식 파일/DB 작업이 제어를 오래 막았고, 그동안 비동기 CARLA 물리는 계속 진행했다. 이전 가속 제어는 목표 속도를 넘겨도 가속할 수 있었으며, 주변 차량에도 앞차 추종 제어가 부족했다. 시나리오 시계의 시간 간격 제한 때문에 실제 주행 시간과 사건 시간이 달라졌다.

왼쪽 차량은 계속 생성된 것이 아니라 고정된 24대를 재배치하고 있었다. 기존 재배치가 속도·조향·주차 브레이크 상태를 충분히 초기화하지 않아 갑자기 튀거나 충돌하는 문제가 있었다.

## 수정한 내용

- 도로 위치 검색을 이전 위치 부근의 작은 구간으로 줄였다. 차량 상태는 같은 물리 프레임의 스냅샷을 이용한다.
- 자차와 주변 차량 모두 앞차 속도·차간 거리·접근 속도를 반영한다. 목표 초과 시 가속하지 않으며, 출발 가속과 일반 감속은 완만하게 한다.
- 실제 물리 시간으로 사건 시계를 진행한다. 준비·일시정지 시간은 주행 시간으로 계산하지 않는다.
- 로그·참가자 DB·Drive 내보내기를 제어와 분리한다. 기록 시각은 저장 완료 시각이 아니라 사건 발생 시각을 유지한다.
- 음성 파일 길이는 출발 전에 준비하고 지도는 재사용한다. 버튼을 누를 때 파일 검증·지도 읽기로 제어가 막히지 않게 한다.
- 빠른 차량을 재배치할 때 이전 제어·각속도를 초기화하고 주변 흐름에 맞는 속도로 넣는다. 추월 요청을 성공시키려고 빠른 차를 인위적으로 감속시키는 처리를 제거했다.
- 거리 벌리기는 목표 간격을 서서히 늘린다. 갓길 진입은 낮은 속도로 공간을 확보하고, 앞으로 이어질 진입 곡선을 미리 조향한다. 차체 모서리까지 갓길/주차 구역 안에 있는지 확인한 뒤 완료한다.
- 모든 차량에 충돌 감지를 붙였다. 제어 지연·접촉·큰 경로 이탈·기록 오류가 발생하면 중단하고 재준비를 요구한다. 오류 상태에서 낡은 실행 요청을 다시 받지 않는다.

## 실제 CARLA에서 확인한 범위

노트북, CARLA 0.9.16, 비동기 물리, 720p 카메라와 연구실 3면 미리보기 구성에서 API로 실제 차량을 움직이며 검사했다. 참가자 실험이 아닌 별도 QA 기록이다.

갓길 정차는 처음에 진입 대기가 반복되었고, 다음 시도에는 조향 지연이 검출됐다. 검출 기준을 완화하지 않고 대기 속도와 진입 곡선 조향을 수정한 뒤 통과했다. 처음 실패한 진단을 성공으로 간주하지 않는다.

관련 자동 검사 114개를 통과했다. 영어·중국어 브라우저 fixture에서 음악 재생 조작, 선택지 표시, 명시적 실행, 언어별 응답, 음성 누락 복구를 확인했다. 음성 VM 검사에서 대응별 사전 안내와 결과 음성의 소유권을 확인했다. 이 검사는 실제 기기에서 들리는 음성이나 차량 제어 검증을 대신하지 않는다.

## 사용과 남은 검증

공유 기준 브랜치는 `codex/portable-motion-20261111`이다. 원인 분석용 브랜치와 구분한다. Git 업데이트 후 실제 실행 중인 `live` 폴더에 수정 코드가 들어가야 하며, 기존 백엔드는 종료하고 다시 시작해야 한다. 실행 후 `/state`의 `runtime_revision`을 확인한다. 엔진·Python·음성 캐시·연구 기록·개별 PC 설정은 Git으로 교체하지 않는다.

노트북 미리보기에서 확인한 주행 안정성은 연구실 3대 모니터·6DoF 검증을 대신하지 않는다. 모션 출력은 이번 검증에서 꺼 두었다. 모든 언어·모든 선택지 조합을 실주행으로 전수 검증한 것은 아니다. 다국어 선택·음성 연결은 별도 UI 검사와 구분한다.

관찰된 노트북 영상 처리 속도는 약 11~14FPS였다. 30FPS는 목표이며 달성 결과가 아니다. 이번 수정의 핵심은 차량 제어 지연과 충돌을 고친 것이다. 빠른 차의 90km/h도 직선 목표값이며 굽은 도로에서는 제한된다. 실제 장비에서는 무인 상태로 연결 확인 후 각 시나리오를 다시 확인한다.

세부 실행 기록은 해당 PC의 `lab-reports`와 `live/native-runs`에 보관한다. 상세 측정·참가자 기록·인증정보는 공개 저장소에 올리지 않는다.
