# 종료 후 다른 시나리오 선택

2026-11-10 · 현재 CARLA 중간발표 내비(`/navigation`)에 적용.

결과 관찰과 정차가 끝나면 결과창에 **시나리오 선택으로** 버튼이 표시됩니다.
누르면 같은 PC·포트의 선택 화면(`/`)으로 돌아가 다른 상황을 고를 수 있습니다.
다음 상황은 자동 실행하지 않으며, 선택한 뒤 기존 준비·출발 순서를 따릅니다.

- 대응 실행 후 완료와, 대응 없이 제한 시간이 끝난 경우를 모두 처리합니다.
- 결과창의 X는 닫기만 합니다. 닫은 뒤에도 복귀 버튼이 남습니다.
- A/B 조건과 한국어·영어·중국어 선택을 복귀 주소에 유지합니다.
- 진행 중·결과 관찰 중에는 완료용 복귀 버튼을 표시하지 않습니다.
- 완료 시 고정 도움·정차 요청은 숨겨 끝난 세션에 새 요청을 보내지 않습니다.
- Git 업데이트 후 실행 중인 앱은 종료·재시작하고 내비를 새로고침합니다.

`test_scenario_return.cjs`는 실제 앱 HTML/JS와 격리된 HTTP 상태로
실행 완료·시간 종료·요청 중단 후 종료 × 한국어·영어·중국어의 아홉 경우를 검사합니다.
복귀·X 닫기 후 복귀·조건/언어 유지·모바일 폭·다음 선택 후 내비 이동을 확인합니다.
실제 CARLA 차량이나 연구실 WebSocket을 움직이는 검사는 아닙니다.
기존 실주행 검사 `test_midterm_browser.cjs`도 새 복귀 흐름에 맞췄습니다.
NuRec/이전 classic 패널은 이번 변경 범위에 포함하지 않습니다.

## 요청 중단 뒤 정차에서 복귀하지 못한 문제

2026-11-10 실제 안개 장면에서 요청 취소 후 차량 속도는 0이지만,
일시정지 때문에 `stopping` 단계가 종료되지 않아 복귀 버튼이 나오지 않는 상태를 확인했습니다.
이미 정차를 요청한 단계에서는 일시정지 중이어도 실제 차량 속도 0.5km/h 미만이 1초 이상
유지되면 종료합니다. 요청 대기·진행·관찰 시간은 일시정지 중에 계속 멈춰 있습니다.
차량이 없거나 아직 움직이면 완료로 처리하지 않습니다. 중단 결과는 성공 대신 `cancelled`로 기록합니다.

연구실 시작 화면 상단에 **시나리오 선택** 버튼도 추가했습니다. 정차 상태에서 같은 화면 안의
선택창으로 돌아가며 B를 기본으로 사용합니다. 기존 ‘내비 전체 화면’ 링크는 실제 `/navigation`으로
바로 열리도록 바로잡았습니다. 영상 창을 모드 전환으로 닫은 직후에는 종료 포트 정리를 잠시 기다립니다.

## 실제 B 주행 점검

현재 로컬 CARLA 3면 미리보기에서 다음 대표 동작을 확인했습니다.

| 상황 | 확인 동작 | 실제 결과 |
|---|---|---|
| 정체 | 트럭과 거리 넓히기 | 완료 후 정차 |
| 안개 | 주변 인식 화면 요청 → 취소 → 일시정지 | 중단 결과 유지, 정차 확인 후 종료 |
| 졸음운전 | 경적 | 1회 동작, 결과 관찰 후 정차 |
| 보행자 | 먼저 건너라고 안내 | 보행자 반응 후 완료·정차 |
| 카풀 | 다른 대기 위치로 이동 | 이동 후 완료·정차 |
| 이상음 | 천천히 가면서 점검 | 감속 후 완료·정차 |

여섯 경우 모두 접촉 기록 0건이며 같은 프레임의 좌·정면·우 영상을 확인했습니다.
개발 API로 수행했고 참가자를 등록하지 않아 참가자 DB에 추가하지 않았습니다.
모든 선택지 조합, 각 장면 전체 시간, 실제 iPad 신규 조작과 연구실 물리 모션의 검증은 아닙니다.
