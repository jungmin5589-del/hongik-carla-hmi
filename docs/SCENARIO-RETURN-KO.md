# 종료 후 다른 시나리오 선택

2026-11-10 · 현재 CARLA 중간발표 내비(`/navigation`)에 적용.

결과 관찰과 정차가 끝나면 결과창에 **시나리오 선택으로** 버튼이 표시됩니다.
누르면 같은 PC·포트의 선택 화면(`/`)으로 돌아가 다른 상황을 고를 수 있습니다.
다음 상황은 자동 실행하지 않으며, 선택한 뒤 기존 준비·출발 순서를 따릅니다.

- 대응 실행 후 완료와, 대응 없이 제한 시간이 끝난 경우를 모두 처리합니다.
- 결과창의 X는 닫기만 합니다. 닫은 뒤에도 복귀 버튼이 남습니다.
- A/B 조건과 한국어·영어 선택을 복귀 주소에 유지합니다.
- 진행 중·결과 관찰 중에는 완료용 복귀 버튼을 표시하지 않습니다.
- 완료 시 고정 도움·정차 요청은 숨겨 끝난 세션에 새 요청을 보내지 않습니다.
- Git 업데이트 후 실행 중인 앱은 종료·재시작하고 내비를 새로고침합니다.

`test_scenario_return.cjs`는 실제 앱 HTML/JS와 격리된 HTTP 상태로
실행 완료·시간 종료 × 한국어 B·영어 A의 네 경우를 검사합니다.
복귀·X 닫기 후 복귀·조건/언어 유지·모바일 폭·다음 선택 후 내비 이동을 확인합니다.
실제 CARLA 차량이나 연구실 WebSocket을 움직이는 검사는 아닙니다.
기존 실주행 검사 `test_midterm_browser.cjs`도 새 복귀 흐름에 맞췄습니다.
NuRec/이전 classic 패널은 이번 변경 범위에 포함하지 않습니다.
