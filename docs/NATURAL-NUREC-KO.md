# NuRec 안개·차량 하부 이상음

실사감에 영향을 주던 가까운 앞차 삽입을 기본 안개 경로에서 제거했습니다.
안개와 이상음은 이미 이용 승인을 받은 같은 원본 고속도로를 사용합니다.
CARLA 자체 렌더링의 여섯 상황은 별도 실행 경로에 그대로 있습니다.

## 실행

기존 NuRec 환경에서 `python open_app.py`를 실행하고 안개 또는 차량 하부 이상음을 선택합니다.
직접 실행은 아래와 같습니다. 원본·GPU 런타임·로컬 음성 캐시는 저장소에 포함하지 않습니다.

```powershell
python launch_live.py --profile fog --quality high
python launch_live.py --profile rattle --quality high
```

기본 `source` 모드는 안개·이상음에 자동 적용됩니다. 기존 비교용 안개는
`--appearance-mode legacy`로만 사용합니다. 렌더러 재사용 시 모드도 확인하므로
이전 세션에서 삽입한 차량이 새로운 기본 모드에 남지 않습니다.

## 원본을 보존하는 범위

- 별도 차량 자산을 삽입하거나 원본 차량을 가까이 이동하지 않습니다.
- 차량 위치는 원본 트랙 사이를 선형 보간하고 회전은 구면 보간합니다.
- 물리 차량은 CARLA에서 실제로 움직이며, 카메라는 원본 촬영 경로 근처에서만
  촬영 리그의 위치·방향으로 안정화합니다. 이 처리는 CARLA 차량을 순간이동시키지 않습니다.
- 옆으로 0.25m 이내, 회전 차이 3도 이내에서 원본 시점을 사용합니다.
  0.65m 또는 12도를 벗어나면 실제 물리 차량의 시점을 사용합니다.
- 원본에 있는 활성 교통은 렌더링하고, 물리 충돌 대리체는 경로에 가까운 최대 10개로 제한합니다.
  전방 원본 차량의 상자 크기를 이용한 추가 간격 감속 장치가 있습니다.
  모든 보이는 물체가 정확한 충돌 메시를 가진다고 주장하지 않습니다.

약 729m / 원본 약 20초 촬영을 약 5분 저속 주행으로 늘립니다. 새 도로 구간을 생성하거나
원본 속도 그대로 5분을 재생하는 방식은 아닙니다. 원본 시간은 실제 차량의 경로 진행량에
연결되므로 차량을 일시정지하면 원본 교통도 멈춥니다. 정차 중 다른 차량의 독립 주행이
핵심인 상황에는 이 기본 모드가 적합하지 않습니다. 재구성 원본 자체의 흐림·누락도
업스케일만으로 복구되지 않습니다.

## 상황과 내비게이션

안개는 주행 10초부터 기존 광학 농도까지 5초 동안 변화합니다. 가능하면 같은 프레임의
거리 정보를 이용해 합성하고, GPU 경로가 없으면 기존 거리 기반 대체 합성을 사용합니다.
실제 기상이나 센서 성능을 검증한 결과가 아닌 실험 자극입니다.
안개 합성 경로의 첫 준비는 출발 전에 수행하고 준비용 영상은 화면에 내보내지 않습니다.
따라서 첫 안개 프레임의 커널 준비가 5초 전환 구간을 끊지 않도록 합니다.

이상음은 주행 8초부터 불규칙한 달그락·딸깍 소리를 냅니다. 기존 하부 커버 소리 생성기를
사용하고 정지·일시정지·숨겨진 탭에서는 끕니다. 브라우저의 첫 소리 재생에는 출발 클릭이 필요합니다.

기존 음악 내비에 홍익 AI 알림을 표시합니다. 승객이 눌렀을 때 캐시된 Sohee 설명을 읽고,
설명 다음에 세로 선택지와 실행 확인을 표시합니다. 음성 호출이나 새 LLM 추론은 사용하지 않습니다.

안개: 안전조치 확인 / 더 감속 / 안전한 곳에 정차 요청.
이상음: 상태 점검 / 관제 지원 요청 / 안전한 곳에 정차 요청 / 주행 유지.
관제 지원은 실제 외부 관제 연결이 아닌 시나리오의 접수 상태입니다.
확인된 대피 공간이 없는 원본이므로 갓길 이동을 만들어내지 않으며 정차 요청은
감속 후 경로 안에서 정지하는 **부분 이행**으로 남깁니다. 안전한 장소에 정차했다고 표시하지 않습니다.

`natural_drive.py`가 원본 교통·카메라·상황 진행을, `scene_bridge.py`가 실제 물리/렌더 연결을,
`navigation_adapter.py`가 선택과 실행을 담당합니다. 30FPS는 목표 상한이며 실제 성능은 별도로 측정합니다.

## 확인한 것과 남은 한계

실제 CARLA 물리 차량과 NuRec을 연결해 720p의 5분 안개 주행을 완료했습니다.
기존 음악 내비에서 홍익 AI 설명과 세로 선택지를 열고, 캐시된 Sohee 음성 재생을 확인했습니다.
이상음의 지원 요청도 실제 주행 감속·결과 관찰·정지까지 연결했습니다.
선택 노출/클릭 기록은 시선 측정이 아닙니다.

빠른 렌더러 후보도 같은 촬영 시점으로 비교했으나 노면과 트럭이 조각나 보이는 현상이 있어
기본값은 기존 `trained` 렌더러를 유지했습니다. 재구성 원본에 남은 노면·가드레일·수목의
흐림과 누락까지 없애는 변경은 아닙니다. 현재 노트북에서 안정적인 30FPS를 달성했다고 주장하지 않습니다.
영상 해상도와 내비의 3D 도형 갱신률, 새 NuRec 프레임의 실제 생성 속도는 서로 다릅니다.
