# 음악 내비와 카풀 대응

2026-11-01. 기존 음악 재생 내비의 HTML·플레이어·지도와 현재 홍익 AI를 함께 사용합니다. 참가자 화면에서 실험용 표기를 제거하고, 실행·화질·재시작 조작은 설정 안으로 옮겼습니다. 기술적 출처·스크립트 상태·실험 로그는 개발 문서와 내부 데이터에 남깁니다. 실제 GPS 지도·상용 서비스로 바뀐 것은 아닙니다.

## 카풀 대기 중 외부인 접근

홍익 AI를 열면 Sohee가 상황을 설명하고 다음 네 선택지를 세로로 표시합니다.

1. **다른 장소로 이동**: 사람이 실제로 물러난 것을 확인한 뒤 같은 주차 구역 안에서 약 6m 이동해 정차합니다.
2. **외부 스피커로 경고**: 사전 생성한 Sohee의 “저는 택시가 아닙니다.”를 재생합니다. 음성 파일은 기존 Qwen 0.6B 캐시에만 저장합니다.
3. **가만히 있는다 (직접 대화)**: 차량을 정차한 채 승객이 직접 말합니다. ‘대화 완료’를 누르기 전에는 사람의 이탈이나 결과 완료를 자동 진행하지 않습니다. 음성 인식이나 대화 이해 기능이 아닙니다. X를 누르면 직접 대화를 취소하고 정차를 유지합니다.
4. **클락션**: 짧은 경적을 한 번 울리고 상대의 반응을 확인합니다. 요청 재전송으로 경적이 중복 실행되지 않습니다.

단순히 설명을 읽거나 선택지만 눌렀을 때는 주행에 반영하지 않습니다. 기존 실행 확인과 결과 피드백을 유지합니다. 결과 안내를 확인하면 내비 화면에 머무릅니다.

## 하부 커버가 흔들리는 소리

일정한 저주파 톤과 고정 반복 루프를 제거했습니다. 서로 다른 8개 짧은 접촉 파형을 불규칙한 간격과 작은 군집으로 재생합니다. 속도에 따라 간격과 강도를 바꾸고, 정차·일시정지·화면 숨김에는 재생 중인 소리를 정리합니다. 기존 차량 이상음 시점과 정차 선택은 유지합니다.

이는 느슨한 하부 커버 접촉을 연상시키는 **절차적 효과음**이며 실제 고장 녹음이나 고장 진단이 아닙니다. 화면에서도 원인을 확정하지 않습니다. 신경망 추론이나 추가 차량·맵 렌더는 없습니다. 새 녹화에서도 같은 접촉 파형을 사용하며 기존 녹화는 덮어쓰지 않습니다.

## 음악과 화면

원래 로컬 음악 5곡의 목록·재생·일시정지·곡 이동·구간 탐색을 복원했습니다. `/media/<known-id>`만 읽으며 바이트 범위와 HEAD를 지원합니다. 파일 경로를 브라우저에 노출하지 않고 경로 탐색으로 다른 파일을 읽을 수 없게 했습니다. 음악 파일은 사용자의 기존 `music` 폴더에 두고 Git에 올리지 않습니다.

홍익 AI 설명과 외부 음성이 나올 때 음악 음량을 낮추고, 소리가 끝나면 사용자가 설정한 음량으로 돌아옵니다. PC와 휴대폰의 참가자 문구를 정차·주변 확인·대응 결과 중심으로 바꿨습니다. 타이머를 실제 도착 예정 시각처럼 표시하지 않습니다.

휴대폰에도 도시 장면의 사전 생성 설명과 직접 대화 완료 상태를 전달합니다. 기존 페어링·Origin·명령 화이트리스트를 유지하고, `study_direct_done`은 서버에 직접 대화 대기 상태가 있을 때만 허용합니다. 휴대폰 기기 청취·실제 참가자 평가는 별도입니다.

## 확인 범위

선택/직접 대화 완료·취소/중복 경적/실제 사람 이탈 후 이동, 음악 HTTP 범위와 경로 경계, 효과음 정지·파형과 가변 간격을 검사합니다. 실제 CARLA에서 네 카풀 행동과 이상음 정차를 끝까지 확인했습니다. 새로운 브라우저 자동화는 로컬 도구 초기화 오류 때문에 픽셀·스피커 검증을 완료하지 못했습니다. 이를 화면 QA나 참가자 연구가 완료됐다고 표현하지 않습니다.
