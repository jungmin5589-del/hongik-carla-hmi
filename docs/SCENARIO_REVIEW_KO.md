# 시나리오 전개와 대응 결과 반복 확인

- 대상: CARLA 4차선 정체(congestion), 졸음운전(night).
- 출발 후 0~30초: 앞차는 차로 중앙을 정상 주행하고 초기 앞차 간격은 약 24m. 시간은 실제 주행 중 누적하는 시뮬레이션 시간이며 준비·일시정지는 제외한다.
- 30~45초: 앞차 목표 간격과 속도/횡방향 움직임이 연속적으로 바뀐다. 차를 화면 앞에 새로 생성하거나 가까운 위치로 옮겨 상황을 만들지 않는다.
- 4차선: 트럭 3대씩 두 열은 처음에는 오른쪽 멀리 앞에서 주행하고, 30초 이후 우리 차량이 느려진 대열에 접근하며 옆으로 나란히 붙는다. 왼쪽 빠른 차량은 처음엔 멀리 앞에 있고 30초 이후 화면 뒤쪽의 안전 확인된 순환 구간으로 들어와 접근한다. 기존 화면 밖 재배치 규칙과 충돌/이탈 중단 장치는 유지한다.
- 졸음운전: 30초까지 앞차의 횡방향 목표는 0이며, 30~40초에 걸쳐 기존 차선 경계 쪽 흔들림으로 전환된다.
- AI ON/OFF는 같은 주행 자극 함수를 사용한다. 안개 등 다른 시나리오의 시작 시점은 이번 변경에 포함하지 않는다.

## 반복 확인

1. 상황 발생 후 하단 물결을 눌러 설명과 대응을 확인한다.
2. 대응을 선택하고 실행한다. 실제 실행·결과 확인·정차까지 지켜본다.
3. 종료 창의 **같은 상황 다시 확인**을 누른다. 새 주행 ID로 같은 시나리오를 준비한다.
4. **출발**을 누르고 다른 대응을 선택해 결과를 비교한다.

참가자 실험은 설문 제출 후 다시 준비할 수 있다. 기존 기록은 덮어쓰지 않는다. 단순 테스트는 참가자 없이 진행한다. 재시작은 즉시 위치만 되돌리는 방식이 아니라 차량과 세션을 다시 준비하므로 준비 시간이 있다.

모든 선택에 대한 실제 주행 검증이 완료됐다는 뜻은 아니다. 원격 주행 결과는 validation의 로컬 검증 기록과 구분해 확인한다. 30FPS 설정값은 실측 성능 보장이 아니다.

## 상황 배너와 대열 표현

- 상황 발생 시 왼쪽에 짧은 설명 배너를 표시하고, 하단 물결의 색을 바꾼다. 미리 준비한 AI 음성은 상황마다 한 번만 재생한다. 기본 설정에서 음성 재생은 사용자의 브라우저 음성 설정·첫 사용자 조작에 따른 재생 허용에 영향을 받는다.
- 배너는 12초 뒤 사라지며 직접 닫을 수도 있다. 물결은 계속 눌러볼 수 있다. 자세히 보기는 기존 상황 설명·대응 창을 연다.
- OFF·연습 회차에서는 상황 배너와 짧은 상황 음성을 표시하지 않는다.
- 오른쪽 대열은 HGV·박스 트럭·미니버스를 섞고 두 열의 앞뒤 위치를 6m 엇갈리게 한다. 동일 차선 내 목표 간격은 15m를 유지하고, 차량이 좌우로 차선을 넘나들게 만들지 않는다. 차종별 실제 제원과 가속력이 달라 실제 배치는 물리 주행 검증이 필요하다.
- 한국어·영어·중국어의 짧은 안내는 research_voice의 alert_* 항목이다. 음성은 별도 cache/research-voice에 보관하며 Git에 포함하지 않는다. 오프라인 음성 재생성과 모델 위치가 다를 때는 HONGIK_TTS_COURSE로 모델/가상환경 루트를 지정할 수 있다.
