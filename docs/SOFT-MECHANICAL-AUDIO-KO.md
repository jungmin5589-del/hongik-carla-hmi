# 더 부드러운 실제 금속 마찰음

사용자가 선택한 후보 4번의 마찰감을 유지하면서 날카로움과 음량을 줄였다.
기존 실시간 하부 커버의 빠른 합성 접촉음 대신 짧게 편집한 실제 녹음이 재생된다.
CARLA 자체 버전과 NuRec 이상음 조건의 공통 내비 사운드 경로에 적용했다.

## 출처와 준비

- 원음: [Metal Scraping.wav](https://freesound.org/people/Doctor_Jekyll/sounds/254064/)
- 제작자: Doctor_Jekyll
- 라이선스: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- 실제 금속 상자를 금속 난간에 미는 녹음이다. 실제 차량 고장 녹음이라는 주장은 하지 않는다.
- 공개 HQ 미리듣기 MP3의 고정 체크섬을 확인한다. 음원은 외장 캐시에 보관하며 Git에는 넣지 않는다.

기존 다운로드 파일을 사용할 때:

```powershell
python prepare_mechanical_recording.py --ffmpeg <FFmpeg.exe> --source <downloaded-preview.mp3>
```

웹 다운로드가 허용되는 환경에서는 `--source` 없이 준비할 수 있다. 사이트가 원본 접근을
거절하면 제한을 우회하지 말고 기존에 정상 다운로드한 동일 파일을 사용한다.

## 소리와 재생

원음의 0.12~2.82초를 발췌했다. 110~1450 Hz 대역으로 필터링하고 앞뒤 140 ms를 완만하게 처리했다.
최대 RMS 0.024, peak 0.16으로 낮췄으며 속도·음높이를 바꾸지 않았다.
2.7초 재생 뒤 약 4.5~8초의 간격을 두며 정차·일시정지·탭 숨김·시나리오 종료 시 해제한다.
AI 설명 중에는 더 낮춘다. 디코딩은 미리 한 번만 하고, 없거나 무결성이 맞지 않으면
합성 소리로 대체하지 않는다. 설정 화면에 제작자·원본·라이선스·편집 내역을 표시한다.

이전 녹화의 소리는 그대로다. 발표용 한영 자료에는 새 소리를 별도 샘플로 추가하여
과거 영상과 현재 구현을 구별했다. 실제 고장 진단이나 참가자 평가 결과로 설명하지 않는다.
