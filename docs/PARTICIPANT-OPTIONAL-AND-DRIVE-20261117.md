# 참가자 없이 테스트 / 참가자 실험 자동 동기화

버전: `20261117-optional-participant`.

- 참가자를 입력하지 않아도 바로 시나리오를 선택할 수 있다. 이 주행은 참가자 실험 DB/CSV에 추가하지 않는다. 개발용 주행 로그는 기존처럼 별도로 남는다.
- 이름 또는 ID를 등록하면 이후 선택한 시나리오부터 참가자별 기록을 남긴다. 상황 발생·선택·실행·완료 시간과 대응 결과를 관리자 페이지에서 확인할 수 있다.
- 등록 모드에서 나가려면 **참가자 없이 테스트**를 누른다. 이전 참가자 기록은 삭제하지 않는다. 진행 중인 실험에서는 참가자를 바꿀 수 없고, 참가자 변경 후에는 시나리오를 새로 선택해야 한다.
- 등록된 실험 기록은 PC DB에 먼저 저장하며 백그라운드 작업이 대략 1초 단위로 변경을 묶어 `trials.csv`, `events.csv`, `research.sqlite3`를 기존 비공개 Drive 폴더에 반영한다. 주행 제어 스레드에서 업로드를 기다리지 않는다.
- Drive 데스크톱이 실행·로그인되어 있어야 클라우드로 올라간다. 실제 서버 반영은 네트워크와 Drive 앱에 따라 더 걸릴 수 있다. 오프라인에서는 PC 기록을 유지하고 연결 후 재시도한다.

이번 PC에서는 Drive 폴더 확인용 파일을 읽지 못해 동기화가 대기 상태였다. 연결된 Drive의 원본 폴더와 확인 파일을 검증한 뒤 같은 내용을 복구하고 로컬 동기화 경로를 명시했다. DB와 두 CSV의 실제 클라우드 수정 시각 갱신까지 확인했다. 계정별 경로와 설정 파일은 공개 저장소에 넣지 않는다.

연구실 PC도 Drive 데스크톱 로그인과 해당 비공개 폴더 연결이 별도로 필요하다. 웹/커넥터 로그인만으로 PC의 자동 동기화가 구성되지는 않는다. 관리자 화면은 ‘Drive 폴더 저장’과 ‘클라우드 업로드’를 구분해서 안내한다.

검증: 익명 모드가 기존 자료를 보존하고 실험 행을 추가하지 않는 검사, 등록 참가자의 선택 이벤트가 수동 동기화 없이 확인된 폴더로 반영되는 검사, 실제 화면의 등록 없는 시나리오 버튼 활성화 및 실제 Drive 파일 갱신을 확인했다.
