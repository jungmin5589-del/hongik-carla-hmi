# 주행·환경음과 횡단보도 보행자

2026-11-03

## 주행·환경음

기존 RGB 주행 화면에는 원본 환경음이 들어 있지 않았고, 내비에서 경적·대사·이상음 같은
별도 효과만 재생했습니다. 이제 같은 내비 페이지에 가벼운 Web Audio 소리 레이어를 추가했습니다.
CARLA 자체 렌더링과 NuRec 내비 양쪽에서 사용합니다. 차량의 실제 속도와 주변 차량 좌표를
받아 타이어/노면·바람·낮은 전동 구동음·근처 교통 소리의 크기를 조절합니다.

이것은 실제 장소의 원음이나 엔진에서 추출한 소리가 아닌 **합성 사운드 디자인**입니다.
Tesla 차량에 맞춰 가솔린 엔진의 큰 공회전 소리를 넣지 않았습니다. 정차 중에는 구동음이 꺼지고
작은 환경음만 남습니다. 일시정지·상황 종료·숨겨진 탭에서는 소리 노드를 정리합니다.
말소리가 재생되면 주행음이 줄어듭니다. 중복 내비 탭의 동시 재생도 제한합니다.

내비의 디스플레이 설정에서 **주행·환경음**과 **주행·환경음 크기**를 조절합니다.
첫 재생은 출발 등의 실제 클릭 후 가능합니다. 소리는 PC의 내비 브라우저가 재생하며
아이폰 알림 페이지에서 같은 주행음을 다시 재생하지 않습니다.

주요 파일은 `driving_sound.js`와 `driving_sound.css`입니다. 추가 GPU 카메라나 음성 모델을
실행하지 않습니다. 기존 MP4 파일의 오디오가 소급해서 바뀌지는 않으며, 기존 효과음만 합치는
오프라인 녹화 스크립트와 브라우저의 실제 음성 출력을 녹음하는 방식은 구분해야 합니다.

## 망설이는 보행자

기다리는 동안 약 반 걸음 내딛기 → 잠깐 멈추기 → 물러서기 → 다시 내딛기를 반복합니다.
작은 시선 변화와 기존 양보 손짓도 유지합니다. 사람의 의도를 인식한 결과가 아니라
`pedestrian_hesitation.py`에 정해진 실험 동작입니다.

위치 이동은 CARLA의 WalkerControl이 처리합니다. 움직이는 사람의 물리 위치를 매 프레임
순간이동시키지 않습니다. 같은 `walker.pedestrian.0001`에서 캡처한 기본 걷기 동작을 재생해
다른 인물의 관절 길이나 위치를 섞지 않습니다. 움직임은 작은 범위에 제한되며, 완전한 횡단은
별도 상태로만 진행합니다. 차량은 대기와 횡단 동안 정차하고 실제 보행자가 벗어난 뒤 출발합니다.

걷기 캐시는 외장 드라이브의 로컬 생성 자료이며 Git에 포함하지 않습니다. 다른 PC에서는 CARLA
보행자 상황을 선택한 뒤 일시정지하고 아래 명령으로 같은 모델의 캐시를 만들고 다시 선택합니다.

```powershell
python prepare_exterior_gait.py --model walker.pedestrian.0001
```

캐시가 없으면 기본 CARLA 걷기로 작동하며 멈춘 상태에서만 손짓 포즈를 적용합니다.

## NuRec의 사람 표현 범위

NuRec에는 사람을 동적 객체로 분류하는 기능이 있습니다. 분류와 실제 움직일 수 있는 별도 모델로
재구성되는 것은 서로 다른 단계입니다. [NVIDIA 동적 트랙 설명](https://docs.nvidia.com/nurec/nurec/dynamic-track-classification.html)

현재 로컬 자료 확인 결과, 안개·하부 이상음의 고속도로 원본에는 사람 트랙이 없습니다.
야간 원본에는 사람 트랙 하나가 있지만, 그것이 임의의 관절 동작을 자유롭게 만들 수 있다는 뜻은 아닙니다.

최신 CARLA 1.0/UE5 문서는 NuRec 배경에 CARLA 차량·보행자를 거리·조명에 맞춰 합성하는 하이브리드
예제를 제공합니다. 우리 고정 환경인 Windows CARLA 0.9.16에 자동 적용되는 기능은 아니며 별도
연동 또는 환경 이전이 필요합니다. 이번 변경에는 해당 이전을 포함하지 않습니다.
[CARLA 하이브리드 렌더링 예제](https://carla-ue5.readthedocs.io/en/latest/nvidia_nurec/#hybrid-rendering-example)
