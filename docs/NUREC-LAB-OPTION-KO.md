# NuRec 3면 비교 옵션 — 2026-11-22

기존 CARLA 실험을 유지하면서 정체·불안정한 앞차 상황을 NuRec으로 확인하는 **개발용 옵션**입니다. 두 엔진의 도로·차량·선택지·주행 길이는 완전히 동일하지 않습니다. 검증 전의 NuRec 실행을 기존 참가자 연구와 동일한 조건으로 취급하지 않습니다.

## 실행

`live/65_START_NUREC_LAB.bat`를 실행하면 `http://127.0.0.1:8779/`에서 CARLA / NuRec, 정체 / 불안정한 앞차를 선택합니다. 기존 실험 페이지 오른쪽 위에도 CARLA / NuRec 링크가 있습니다. 준비가 끝나면 기존 내비게이션이 열리며 출발 버튼으로 시작합니다.

NuRec 모델·CARLA 설치·기존 Python·Ubuntu-22.04 Docker 환경은 별도로 필요합니다. GitHub에는 모델과 NVIDIA SDK를 넣지 않습니다. 원본 SSD가 없으면 현재 주행을 종료하기 전에 오류를 표시합니다. 실행 중이거나 일시정지한 미완료 주행은 엔진 변경으로 종료하지 않습니다.

코드를 연구실에 배포할 때는 기존 `live` 폴더에서 Git pull을 합니다. 선택 화면은 별도 NuRec 실행 폴더에도 허용한 코드를 백업 후 반영합니다. 원본·모델·인증서·연구 기록을 복사하거나 덮어쓰지 않습니다. 미리 배포 상태를 확인하거나 수동 반영하려면 아래 명령을 사용합니다.

```powershell
python deploy_nurec_option.py --check
python deploy_nurec_option.py
```

NuRec 원본은 `HONGIK_NUREC_ROOT`, 기존 설치 부모 폴더, 연결된 SSD의 알려진 설치 위치 순서로 찾습니다. `/mnt/d/...`로 저장된 검증 기록은 현재 SSD 위치의 같은 원본 파일로 해석합니다. 파일 크기와 기존 검증 상태를 확인하며 새로운 원본으로 대체하지 않습니다. WSL 배포판 등록의 VHD 경로는 별개입니다. 드라이브 문자가 바뀌면 그 등록 경로도 확인해야 합니다.

## 화면

- 전체: **5760 × 1080 / 16:3**, 화면당 16:9.
- 실제 좌·중·우 카메라 세 방향을 각각 요청합니다. 각 수평 시야각 72°, 방향은 −66° / 6° / 78°입니다.
- 세 화면은 같은 장면 시각과 같은 차량 포즈 목록을 사용합니다. 하나라도 실패하거나 주행 세션이 바뀌면 불완전한 세트는 표시하지 않습니다.
- 노트북과 포터블 모니터에서도 전체 16:3 화면을 비율 유지해 표시합니다. 보조 모니터라고 중앙 한 화면으로 바꾸지 않습니다.
- NuRec 기본 화질은 화면당 960 × 540입니다. 1280 × 720도 선택할 수 있습니다. 5760 × 1080 출력은 렌더 해상도와 다릅니다.
- 순차 렌더링으로 GPU 최고 메모리 사용을 줄입니다. 세 화면 비용이 추가되므로 30fps를 보장하지 않습니다. 화면에 실제 발행 간격으로 계산한 FPS를 표시합니다. 정차 중에는 렌더 호출을 줄입니다.
- NuRec은 원본 센서의 위치·높이를 유지합니다. CARLA와 동일한 차체·눈 위치를 재현했다는 뜻은 아닙니다.

## 움직임과 대응

처음 30초는 정상 주행 후 상황이 생깁니다. 졸음운전 앞차의 차체 방향은 횡방향 움직임의 기울기와 일치시켜 옆으로 미끄러지는 느낌을 줄입니다. 짧은 촬영 구간은 실제 길이에 맞춰 속도를 낮추며 도로를 임의로 늘리거나 배경을 반복하지 않습니다.

정체는 오른쪽 두 차로에 각 3대의 대형차를 두고, 왼쪽에는 고정된 24대 풀을 사용합니다. 왼쪽 차는 기본 13m 배치이며 앞쪽 약 232m를 벗어난 뒤 뒤쪽 80m로 재배치합니다. 가까이 보이는 차량을 순간 이동시키거나 차량 수를 계속 늘리지 않습니다. 이 수치는 스크립트 설정이고 실제 인지·관제 결과가 아닙니다.

NuRec의 기본 대응은 경적 / 차간 거리 넓히기 / 주행 유지입니다. Hongiki의 기존 웨이브·상황 배너·설명·세로 선택지를 사용합니다. 요청을 설명하는 음성과 취소 가능한 대기 시간을 거친 뒤 반영합니다. 실행 결과를 관찰하고 감속해 종료합니다. 경적은 안개나 정체 자체를 해결하지 않습니다. 지원 요청은 기록만 하며 실제 상담원 연결을 주장하지 않습니다. 확인된 갓길이 없어 정차 요청은 현재 경로에서 감속하는 방식입니다.

**스캔한 차량은 강체 Gaussian 자산입니다. 바퀴가 독립적으로 회전하는 모델이 아니므로, 이번 변경만으로 CARLA 수준의 바퀴 애니메이션이나 모든 시점의 실사감을 보장할 수 없습니다.** 원본 촬영에 없던 방향에서는 건물·차량이 깨져 보일 수도 있습니다. 자연스러움은 실제 화면 확인이 필요합니다.
