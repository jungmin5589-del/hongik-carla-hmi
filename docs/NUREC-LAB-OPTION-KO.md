기존 CARLA 실험을 유지하면서 정체·불안정한 앞차 상황을 NuRec으로 확인하는 **개발용 옵션**입니다. 두 엔진의 도로·차량·선택지·주행 길이는 완전히 동일하지 않습니다. 검증 전의 NuRec 실행을 기존 참가자 연구와 동일한 조건으로 취급하지 않습니다.

## 실행

연구실 PC에서 처음 쓸 때는 **66_NUREC_SETUP.bat → 65_START_NUREC_LAB.bat** 순서입니다. 66번은 SSD 안에 별도 NuRec 전용 Python을 만들어 고정 패키지를 설치하고, 이미 준비된 전용 Python은 재사용합니다. 기존 CARLA Python을 변경하지 않습니다. SSD의 준비된 ext4 VHD를 해당 PC에 등록하며, 기존의 다른 WSL 배포판은 삭제·덮어쓰기하지 않습니다. 필수 좌표 변환 헬퍼도 원본 라이선스 표시를 유지해 SSD에 보관하여 전체 Unreal 소스 체크아웃에 의존하지 않습니다.

이 방식은 **SSD의 모델과 WSL VHD를 계속 사용하는 구성**입니다. 연구실 PC의 내부 SSD로 모든 데이터를 복사·이전한 상태가 아닙니다. 사용 후에는 **67_STOP_NUREC_LAB.bat**로 해당 NuRec 환경과 전용 WSL을 종료한 다음 Windows의 안전 제거를 사용합니다.

Windows에 WSL2 자체가 없거나 기능 활성화 후 재시작이 필요한 경우에는 Windows 설치 단계를 먼저 마쳐야 합니다. 자동으로 PC를 재시작하지 않습니다. [Microsoft WSL 설치·VHD 등록 명령](https://learn.microsoft.com/en-us/windows/wsl/basic-commands)을 따릅니다. 준비된 Docker/NVIDIA 런타임과 고정 NuRec 이미지는 기존 VHD에서 재사용합니다. 새 Linux 환경을 따로 구성할 때의 GPU 컨테이너 연결은 [NVIDIA 공식 설치 안내](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html)를 따릅니다.

PC별 Python·엔진 경로는 Windows 사용자 로컬 앱 데이터의 `HongikDrive/nurec-setup.json`에 저장합니다. 노트북의 `C:/CARLA_0.9.16` 경로를 연구실에 강제하지 않습니다. 설치 점검은 모델 재학습을 수행하지 않습니다.

`live/65_START_NUREC_LAB.bat`를 실행하면 `http://127.0.0.1:8779/`에서 CARLA / NuRec, 정체 / 불안정한 앞차를 선택합니다. 기존 실험 페이지 오른쪽 위에도 CARLA / NuRec 링크가 있습니다. 준비가 끝나면 기존 내비게이션이 열리며 출발 버튼으로 시작합니다.

NuRec 모델·CARLA 설치·기존 Python·Ubuntu-22.04 Docker 환경은 별도로 필요합니다. GitHub에는 모델과 NVIDIA SDK를 넣지 않습니다. 원본 SSD가 없으면 현재 주행을 종료하기 전에 오류를 표시합니다. 실행 중이거나 일시정지한 미완료 주행은 엔진 변경으로 종료하지 않습니다.

코드를 연구실에 배포할 때는 기존 `live` 폴더에서 Git pull을 합니다. 선택 화면은 별도 NuRec 실행 폴더에도 허용한 코드를 백업 후 반영합니다. 원본·모델·인증서·연구 기록을 복사하거나 덮어쓰지 않습니다. 미리 배포 상태를 확인하거나 수동 반영하려면 아래 명령을 사용합니다.

```powershell
python deploy_nurec_option.py --check
python deploy_nurec_option.py
```

NuRec 원본은 `HONGIK_NUREC_ROOT`, 기존 설치 부모 폴더, 연결된 SSD의 알려진 설치 위치 순서로 찾습니다. `/mnt/d/...`로 저장된 검증 기록은 현재 SSD 위치의 같은 원본 파일로 해석합니다. 파일 크기와 기존 검증 상태를 확인하며 새로운 원본으로 대체하지 않습니다. WSL 배포판 등록의 VHD 경로는 별개입니다. 드라이브 문자가 바뀌면 그 등록 경로도 확인해야 합니다.

- NuRec은 원본 센서의 위치·높이를 유지합니다. CARLA와 동일한 차체·눈 위치를 재현했다는 뜻은 아닙니다.
