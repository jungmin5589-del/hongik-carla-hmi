# 실험 모드 빠른 안내

- 기존 네비게이션은 유지하고, 새 실험은 `64_START_EXPERIMENT.bat`로 엽니다.
- 음성 인식 설치는 PC마다 한 번 `63_SETUP_LOCAL_STT.bat`를 실행합니다.
  별도 시스템 Python 3.12가 필요하며 CARLA용 Python은 변경하지 않습니다.
- 순서: 2분 연습 → 정체 AI OFF → 정체 AI ON → 졸음운전 AI OFF → AI ON.
- 참가자 ID를 넣으면 기존 비공개 기록과 Drive 동기화에 연결됩니다.
  테스트만 할 때는 참가자 없이 실행할 수 있습니다.
- OFF는 AI 상태 설명·알림·입력을 숨깁니다. 기존 조건 A와 다릅니다.
- ON은 기존 알림·세로 선택지에 더해 텍스트와 마이크 입력을 지원합니다.
- 음성을 텍스트로 확인한 뒤 실행을 눌러야 차량 동작을 요청합니다.
  모호하거나 지원하지 않는 요청은 실행하지 않습니다.
- ‘알려 줘’는 변화가 확인됐을 때 다시 알리고, 그 뒤 20초를 관찰합니다.
  변화가 없거나 설명만 본 경우는 기본 5분 주행을 유지합니다.
- 아이패드 마이크는 기존 인증서가 적용된 HTTPS 주소와 Safari 권한이
  필요합니다. 일반 HTTP에서도 기존 화면·텍스트·선택지는 쓸 수 있습니다.
- 마이크는 버튼을 눌렀을 때만 받습니다. 상시 호출어나 무제한 대화는 아닙니다.
- 소리는 PC에서 인식하며 유료 API를 호출하지 않습니다. 출력 음성은
  기존 Qwen/Sohee의 미리 만든 녹음을 재생합니다.
- 연구실에서는 코드 Pull 외에 **최신 SSD의 `cache/research-voice` 폴더**도
  기존 캐시를 백업한 뒤 복사해야 새 재알림 음성이 나옵니다. 녹음 파일은
  Git에 포함하지 않습니다. STT 모델은 연구실 PC에서 한 번 준비합니다.

기술 구성·제약·검증 구분은 [상세 안내](EXPERIMENT_STT.md)를 확인하세요.
연구실의 실제 마이크·소음·아이패드·3면 화면 검증은 별도로 해야 합니다.
