# 보행자와 차량이 서로 양보하는 실험

50번 CARLA 시작 화면의 네 번째 **보행자와 서로 양보**를 선택한다.
기존 정체·야간·안개 세 시나리오는 유지하며 NuRec 48번에는 추가하지 않았다.
이 조건은 Town03의 실제 횡단보도 형상과 기본 보행자 모델을 사용한다.
맵의 신호등은 이 전용 실험 월드에서 꺼서 무신호 조건을 구성한다.
실제 도시의 신호 없는 횡단보도를 검증·복제한 것은 아니다.

## 진행

1. 차량은 최대 15km/h로 접근한다. 보행자는 횡단보도 진입부로 약 두 걸음 이동한다.
2. 차량은 횡단보도 앞에서 정차한다. 보행자는 차량 쪽으로 돌아 손짓하며 기다린다.
3. 홍익 AI 버튼이 기존 알림 방식으로 표시된다. 승객이 열면 설명과 세 선택지가 나온다.
4. 선택 후 실행을 확인해야 요청이 적용된다. X는 창을 닫으며 요청을 실행하지 않는다.
5. 실제 보행자가 횡단을 마치고 반대편 가장자리로 이동해 횡단 구간을 벗어난 것을 확인한다.
6. 2초 동안 확인한 뒤 차량이 약 20m 진행하고 정지하며 결과 안내로 끝난다.

보행자가 횡단 중인 상태에서는 승객에게 강제 출발 선택을 제공하지 않는다.
자율주행차의 보행자 보호 판단을 승객이 해제하는 실험이 아니다.

## 선택과 차이

| 선택 | 연출 |
|---|---|
| 양보 안내 보내기 | 저장된 Sohee 음성으로 외부 안내를 표현한다. 약 2.5초 후 보행자가 횡단한다. |
| 관제 확인 요청 | 6초의 모의 확인 뒤 보행자가 횡단한다. 실제 상담원·통신망에 연결하지 않는다. |
| 그대로 기다리기 | 상황 시작 뒤 28초까지 기다린 후 보행자가 횡단한다. |
| 선택하지 않기 / X | 같은 28초 기본 처리를 유지한다. 개입하지 않아도 상황이 끝난다. |

빠른 대응으로 대기 시간을 줄이는 차이가 있으므로, 행동 선택에 대한 결과의 유불리가
연구 결과에 영향을 줄 수 있다. 최종 참가자 실험 전에는 타이밍·순서·설명량과 질문을 검토한다.
관제 요청과 대기에는 기존 명령 식별자를 재사용하지만 의미는 이 조건의 전용 설명을 따른다.
보행자 안내는 경적을 울리는 동작이 아니며 경적 횟수는 증가하지 않는다.

## 구현과 음성

- `pedestrian_yield.py`: 실제 맵 경로, 보행자 생성·관절 동작, 상태 전환, 실제 위치 기반 재출발.
- `pedestrian_gesture.py`: 상완·전완을 연결한 손짓. 손목은 기본 자세를 유지하고 팔 올림·내림을 부드럽게 연결한다.
- `pedestrian_ui.js`: 전용 내비 문구와 외부 안내 음성 재생.
- `pedestrian_voice.py`: 기존 음성 캐시를 건드리지 않는 별도 Sohee 파일 검증.
- `prepare_pedestrian_voice.py`: 기존 로컬 Qwen 환경으로 안내 두 문장을 한 번 사전 합성한다.
- `../cache/sohee-pedestrian/`: 로컬 WAV와 매니페스트. Git에는 포함하지 않는다.

홍익 AI 설명은 클릭할 때 저장된 Sohee를 재생한다. 외부 안내 음성은 같은 PC의
내비에서 재생하는 실험 표현이며 실제 외부 스피커나 위치 기반 공간 음향은 아니다.
주행 프로세스는 Qwen 모델을 로드하지 않는다. 캐시가 없으면 텍스트 설명을 유지하고
음성을 준비하지 못했다고 표시하며 다른 TTS로 자동 대체하지 않는다.

## 검증과 제한

`python -m unittest test_native_carla test_pedestrian_yield test_presentation test_repo_safety`
로 상태 전환, 일시정지, 실제 위치가 남아 있을 때 정지 유지, 선택·실행 확인과 중복 방지를 검사한다.
`validate_pedestrian_yield.py --action notice|support|wait|none`은 실제 실행 중인 CARLA에서
대기·횡단·재출발·종료와 횡단 중 차량 속도를 확인하고 RGB·로그를 D의 validation에 저장한다.

몸동작과 반응은 정해진 시나리오다. 영상으로 손짓이나 횡단 의도를 인식하는 모델이 아니다.
관절로 만든 손짓은 기본 캐릭터 애니메이션 수준이며 모션캡처 품질은 아니다.
이 짧은 장면은 기존 고속도로의 5분 주행 조건과 길이가 다르다.
개발 QA는 참가자 반응, 실제 도로 안전성, 안정적인 30fps 또는 연구실 3면 성능 검증이 아니다.
