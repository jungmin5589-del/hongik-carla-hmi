# 보행자와 차량의 상호 양보

50번 시작 화면의 ④ 보행자와 서로 양보를 선택한다.
현재의 세 상호작용 조건은 [공통 실행·음성·검증 안내](CITY-CASES-KO.md)를 따른다.

홍익 AI 클릭 → Sohee 상황 설명 → 세로 선택지 → 실행 확인 → 실제 반응 → 종료 순서다.
설명을 다 듣거나 대응 방법 보기를 누르면 선택지가 나타난다. ETA는 표시하지 않는다.

| 선택 | 동작 |
|---|---|
| 클락션 | 경적 한 번과 보행자 반응 |
| 하이빔 | CARLA 상향등 두 번 점멸과 보행자 반응 |
| 직접 대응 | 승객이 말한 뒤 대응 완료 버튼으로 끝냄. 음성 인식 없음. |
| 기다리기 | 추가 자극 없이 보행자가 움직이기를 기다림 |

횡단 중에는 차량을 강제로 출발시킬 수 없다. 실제 보행자가 횡단 구간을 벗어나야
차량이 다시 출발한다. 약한 손짓은 연결된 팔 관절로 만들며 손목은 기본 자세를 유지한다.
이 조건의 Town03 신호등을 꺼서 무신호 상황을 연출하며 실제 한국 도로를 복제한 것은 아니다.

`python validate_pedestrian_yield.py --action horn|highbeam|direct|wait|none`은 실제 CARLA를 검사한다.
`node test_pedestrian_browser.cjs`는 별도의 빈 테스트 브라우저에서 최신 흐름을 검사한다.

이전 버전의 양보 안내/관제 선택은 사용자 피드백에 따라 위 네 선택지로 변경됐다.
손짓 인식 AI, 실제 관제, 실차 안전성, 참가자 효과를 검증한 시스템은 아니다.
