# 주행 후 설문과 비상 정지

주행이 완료되면 내비게이션에 설문을 자동 표시합니다. 연습 회차는 제외합니다.
질문은 Pretendard 750, 제목은 800 굵기로 기존 내비게이션과 맞췄습니다.

- 공통: 상황 이해, 감정, 원했던 대응, 불안·답답함·통제감·이해도(7점).
- AI ON: 알림 인지, 선택/입력 이유, 기대와 실제 결과, 요청 적합성(5점/해당 없음).
- 서술형은 선택, 척도는 필수입니다. 모든 응답에는 설문 버전이 함께 저장됩니다.
- 작성 중 자동 임시 저장하며 새로고침 후 복원합니다. 제출 뒤에는 수정되지
  않으며 같은 제출 재전송은 중복 행을 만들지 않습니다.
- 등록된 참가자는 설문 제출 후 다음 시나리오로 이동할 수 있습니다.
  설문 창을 닫아도 ‘주행 후 설문 작성’ 버튼으로 다시 열 수 있습니다.
- 참가자 없이 테스트하면 설문도 시험해 볼 수 있지만 참가자 DB에는 저장하지
  않습니다. 실제 실험은 참가자 이름 또는 ID를 먼저 등록하세요.

선택·취소·실행·완료 이벤트와 설문은 동일한 trial_id로 연결합니다.
등록된 참가자 주행에는 약 1초 간격으로 속도, 앞차 간격(있는 경우),
차로 오차, 차로 내 위치(있는 경우), 조향 명령, 대응 단계를 추가 기록합니다.
이는 시뮬레이터 상태이며 시선·생체 신호·실차 CAN 데이터가 아닙니다.
짧은 틱 사이의 모든 신호를 기록하는 원시 고주파 계측도 아닙니다.

주행 루프는 기존 비동기 기록 큐로 샘플을 보냅니다. 신호 샘플마다 Drive
복사를 실행하지 않고 주기적으로 내보내며, 선택과 설문 저장은 기존 알림
경로를 사용합니다. Drive 업로드 완료 여부는 Drive 앱의 연결 상태에 따릅니다.

관리자 화면에서 참가자 행을 선택하면 설문과 행동 타임라인, 차량 신호를
함께 볼 수 있습니다. 실행 요약의 설문 제출 상태와 ‘설문 CSV’도 추가했습니다.
PC의 기존 비공개 research.sqlite3와 exports/surveys.csv에 저장하고,
기존 확인된 비공개 Drive 대상에 events.csv·trials.csv·DB와 함께 미러링합니다.
기존 데이터는 유지하며 surveys 테이블을 추가합니다. 데이터 초기화 시에는
설문까지 먼저 백업합니다. 코드 GitHub 공유에 응답·모델·측정 파일을 포함하지
않습니다. 기존 관리자 ‘GitHub 공개 저장’은 별도 수동 동작이므로 실험 기록의
비공개 보관에는 사용하지 마세요.

화면의 ‘비상 정지’를 누르면 “비상 정지를 원하시면 실험이 종료됩니다.
정말 멈추시겠습니까?”와 예·아니요를 표시합니다. 아니요는 차량에 명령을
보내지 않습니다. 예는 정지를 요청하고 실제 차량이 멈춘 뒤 실험을 종료해
설문을 엽니다. 정지 처리 중 재출발은 거부합니다. 이 확인창은 승객용 실험
화면에만 해당하며 물리 시뮬레이터의 하드웨어 비상 정지 장치는 변경하지 않습니다.

PC에서 시나리오 선택을 접수하면 기본 브라우저에 내비를 열고 차량 준비 상태를 안내합니다.
진행 화면은 유지해 중복 내비와 음성 재생을 줄입니다. 아이패드는 같은 탭에서 전환합니다.
CARLA 주행 창은 신규 장면 준비 시 복원·표시 요청을 받습니다. 노트북 미리보기
모드에서 별도 확장 모니터가 감지되면 그 화면에 중앙 카메라를 표시하고,
모니터가 하나면 기존 미리보기를 사용합니다. 연구실 Surround는 기존 3면을
유지합니다. 실제 확장 모니터 배치는 장비 연결 후 확인해야 합니다.
