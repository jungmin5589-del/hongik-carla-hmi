# 초보·졸음운전 자극과 왼쪽 진입 수정

첫 30초의 정상 도입, 같은 OFF/ON 물리 자극과 기존 요청 확인·실행 API를 유지합니다. 이번 수정은 CARLA 자체 렌더링에 적용하며 NuRec의 강체 차량 조작과는 별도입니다.

## 변경

- 초보운전 간격: 첫 30초의 목표 24m에서 45초에 범퍼 사이 목표 4m로 점진적으로 줄입니다. 기존 목표 5.5m보다 가깝게 설정하며 실제 속도·접근 속도에 따른 제동 제한을 유지합니다.
- 초보운전 앞차: 속도 변동과 주기적인 큰 감속 후 재가속, 차로 중심에서 좌우 최대 약 0.7m 움직임. 급정지처럼 느껴지는 망설임을 목표로 하되 목표 속도를 순간적으로 0으로 만들지 않습니다.
- 제동 표시: 실제 제어의 브레이크 입력에 맞춰 선행차·주변차의 브레이크등도 점등합니다. 감속을 시각적으로 확인할 수 있게 하며 ego 상향등 기능을 유지합니다.
- 졸음운전 앞차: 좌우 휘청임과 별개로 속도 변화·간헐적 감속을 추가합니다. 원인 추정이나 졸음 감지 결과가 아닌 스크립트 자극입니다.
- 왼쪽 교통: 고정된 24대 풀, 여러 차종, 16~23m의 불규칙한 묶음 간격과 약 267m의 큰 틈. 직선에서는 약 90km/h, 곡선에서는 기존 곡률 속도 제한을 따릅니다. 요청을 누른 순간 차량을 옮겨 틈을 만드는 방식이 아닙니다.
- 졸음운전 주변: 왼쪽 차로와 맨 오른쪽 차로에 배경 차량 6대를 추가합니다. 휘청이는 선행차가 걸치는 바로 오른쪽 차로는 비워 옆을 지나던 배경차와의 접촉을 피합니다. 기존 물리 추종·곡선 감속·화면 밖 재사용을 적용하며, 정체 장면보다 짧은 420m 재사용 구간으로 긴 시간 동안 모두 멀어져 버리는 현상을 줄입니다.
- 왼쪽 이동: 경과 시간으로 횡이동 위치를 계산하던 것을 40m의 연속된 지도 경로로 변경했습니다. 실제 이동이 멈추면 횡방향 목표도 진행하지 않습니다. 조향의 앞쪽 미리보기에도 같은 경로를 사용합니다.
- 진입 전에는 후방 접근 시간을 8초 기준으로 검사하고, 안전한 상태가 1.5초 지속된 뒤 시작합니다. 안전한 틈이 없으면 기다리고 대기 이유를 안내합니다. 대기는 최대 120초 기준으로 확인하며 미완료를 완료로 기록하지 않습니다.

충돌·기록 오류·제어 지연·차로 이탈 중단 장치와 16GiB/2GiB 메모리 기준을 유지합니다. 안전 확인 없이 추월을 강제로 성공시키지 않습니다. 실제 체감은 목표 값뿐 아니라 차량 물리·곡선·주변 교통에 따라 달라집니다.

## 파일

`traffic_intro.py`: 선행차 움직임·플래툰·속도 함수.
`native_carla.py`: 여러 차종 배치·야간 주변 교통·물리 재사용 연결.
`midterm_study.py`: 지도 경로 기반 왼쪽 이동·대기 안내·완료 판정.
`validate_driver_choices.py`: 참가자 없는 실제 주행 선택 검증. 세션 유지·충돌·가드·완료 상태와 실제 영상을 로컬에 기록합니다. UI 열람 검증과 참가자 실험 결과를 대신하지 않습니다.

## 연구실 주의

이전 PDF의 연구실 추종·페달 평활·6축 보정·Rust DLL은 확보하지 못했습니다. `vehicle_following.py`, collector, 모션 코드와 DLL은 이번에 수정하지 않았습니다. 연구실 제어 수정본 위에 native_carla.py 전체를 덮어쓰지 말고 수정본을 보존한 브랜치에서 병합해야 합니다. 실제 리그는 모션 OFF 화면 검증 뒤 별도 재검증합니다.


## 노트북 실제 검증 · 2026-11-28

CARLA 0.9.16, 비동기 물리, 3면 카메라 각 720p, 모션 OFF, 참가자 없는 개발 시험입니다. Python 관련 검사 84개와 언어 검사 5개가 통과했습니다. 추가한 대기·차로 이동 안내는 영어와 중국어로도 제공됩니다.

| 실제 시험 | 최종 결과 |
| --- | --- |
| 초보운전: 왼쪽 차로 진입·거리 확보·경적 | 각 요청 적용 → 20초 결과 관찰 → 정차 완료, 충돌 0 |
| 졸음운전: 추월·거리 확보·경적 | 각 요청 적용 → 20초 결과 관찰 → 정차 완료, 충돌 0 |
| 초보운전: 대응 없이 5분 연속 주행 | 정차까지 완료, 충돌 0, 차량 32대·동일 세션 유지 |
| 졸음운전: 대응 없이 5분 연속 주행 | 정차까지 완료, 충돌 0, 차량 8대·동일 세션 유지 |

초보운전 기본 주행의 상황 발생 후 범퍼 간격은 약 4.1~8.3m였습니다. 4m는 목표값이며 실제 간격은 제동 제한과 앞차 움직임에 따라 달라집니다. 졸음운전 시험에서는 전방 150m 안에 배경 차량이 없는 가장 긴 구간이 약 8초였고, 앞차는 약 10~38km/h로 변했습니다. 이는 이번 한 번의 개발 시험에서 관측한 범위입니다.

초보운전 진입·거리 확보의 개별 시험은 v6, 나머지 대응과 두 5분 주행은 v8입니다. 두 버전의 초보운전 제어는 같고, v8에는 브레이크등 표시와 졸음운전 배경차 배치 보정이 추가됐습니다. 실제 차량의 브레이크 입력과 등화 상태도 외부 CARLA 클라이언트로 확인했습니다.

중간 v6 졸음운전 거리 확보 시험에서는 선행차와 바로 오른쪽 배경차가 옆면 접촉했습니다. 충돌 센서가 중단했고, 해당 실패 기록을 보존했습니다. 배경차를 바깥 차로로 옮긴 v8에서 같은 분기와 5분 주행을 재검증했습니다. 대기 차량을 지우거나 충돌 판정을 끄는 방식으로 해결하지 않았습니다.

선택 시험은 내비와 같은 명령 API를 사용해 세션 유지·물리 동작·실제 완료를 검사했습니다. 브라우저 버튼 직접 터치, 실제 음성 청취, 아이패드 및 물리 6축 장비 검증을 대신하지 않습니다. 모든 선택지·모든 초기 조건의 무충돌을 보장하는 결과도 아닙니다. 원본 상태 기록과 실제 화면은 SSD의 `lab-reports/driver-choices-v6-20261128` 및 `driver-choices-v8-20261128`에 보관하며 Git에는 올리지 않습니다.
