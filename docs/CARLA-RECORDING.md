# CARLA 화면과 장면 소리만 저장

별도의 녹화 페이지를 열거나 내비를 조작하지 않고, 기존 **50번 CARLA native 앱**에서 여섯 장면을 순서대로 저장합니다.

```powershell
python record_scene_with_assets.py
# 한 장면만: python record_scene_with_assets.py --profiles carpool
```

기존 native 가상환경과 연결된 외장 SSD가 필요합니다. 같은 장면을 재설정해 출발부터 실제 종료까지 기록합니다. 기본 대기/유지로 진행하며, 홍익 AI 설명이나 선택 동작을 시연하지 않습니다. CARLA RGB 영상만 담기므로 내비·녹화 버튼·PC 바탕화면은 영상에 없습니다.

소리는 PC 스피커를 녹음한 것이 아닙니다. 실제 CARLA 상태를 영상과 같은 단조 시계로 기록하고, **기존 검증된 취객 대사 파일과 기존 발소리·문 두드림·기계음 파형**을 해당 사건의 시간에 맞춰 합칩니다. 마이크나 다른 앱 소리를 수집하지 않고, 음성 모델을 다시 추론하지 않습니다. 여섯 대사 누락이나 문 두드림 이벤트 누락은 완료 처리하지 않습니다. 브라우저 필터의 정확한 출력 복제나 하드웨어 동기 녹음을 주장하지 않습니다.

native 서버는 기존 성능 설정의 `-nosound`로 실행됩니다. 현재 엔진/도로 배경음은 없고, 없는 엔진음을 추가하지 않습니다. 별도 장면 효과가 발생하지 않는 기본 주행 구간은 무음입니다. 효과음이 없는 구간에도 정상 AAC 오디오 트랙을 포함합니다.

프레임은 기존 RGB 스트림에서 받아 실제 도착 간격대로 기록합니다. 주행 중 인코딩하지 않고 장면이 끝나면 H.264 영상과 AAC 소리를 합칩니다. 30fps 파일 형식은 실제 CARLA 30fps 성능을 증명하지 않습니다. 기존 비동기 물리·DX12·시작 메모리 기준을 유지하고, 녹화 중에도 기존 2GiB 커밋 메모리 여유 기준을 적용합니다.

영상·WAV·프레임·상세 로그는 기존 프로젝트의 D 드라이브 `recordings`에 둡니다. 수업 폴더 **시나리오별 주행영상**에는 작은 바로가기와 목록만 만듭니다. GitHub에는 코드와 설명서만 올립니다.

검증은 완료 상태, 여섯 대사/이벤트 시간, 효과음 구간, 전체 MP4 영상·오디오 디코딩을 확인합니다. 이는 개발 검증이며 실제 참가자 연구나 스피커 청취 검증을 뜻하지 않습니다.
