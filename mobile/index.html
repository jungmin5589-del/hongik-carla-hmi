같은 Wi-Fi에서 사용해요. 아래 설정은 아이폰에서 직접 진행해 주세요.

1. 이 PC의 연구용 인증서 준비

인증서를 신뢰하면 이 PC가 발급하는 인증서를 아이폰이 신뢰하게 됩니다. PC의 ‘휴대폰 연결’ 화면에 표시된 인증서 지문을 확인한 뒤 진행해 주세요.

연구용 공개 인증서 다운로드

설정 → 프로파일이 다운로드됨 → ‘Hongik AI local research CA’ 확인·설치. 이후 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 같은 이름을 직접 확인·신뢰합니다. 프로파일 메뉴가 없으면 일반 → VPN 및 기기 관리에서 확인해 주세요.

이 앱은 아이폰의 신뢰 설정을 자동으로 바꾸지 않습니다. 인증서 경고가 계속되면 다음 단계로 진행하지 말고 PC 주소와 인증서를 다시 확인해 주세요.

2. 보안 주소로 다시 연결

PC의 ‘휴대폰 연결’ 화면을 새로고침해 새 코드를 확인한 뒤, 아래 보안 주소를 열고 연결 코드 6자리를 입력해 주세요. 기존 HTTP 연결은 해제됩니다.

보안 주소 열기

3. 홈 화면에 추가하고 알림 허용

보안 주소를 Safari에서 연 뒤 공유 버튼 → ‘홈 화면에 추가’. 홈 화면의 홍익 AI를 열고 설정 → ‘아이폰 시스템 알림 켜기’ → 허용을 누르세요.

‘알림 받아보기’를 누르고 아이폰을 잠가 실제로 도착하는지 확인해 주세요. 알림을 눌러 앱을 연 다음 행동을 선택합니다. PC와 같은 Wi-Fi가 연결되어 있어야 행동 요청이 전달됩니다.

일반 HTTP 연결에서는 앱을 열어둔 동안의 배너와 선택만 사용할 수 있어요.
